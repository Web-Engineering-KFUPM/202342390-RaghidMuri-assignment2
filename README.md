# Raghid Muri Portfolio

## Project Description
This is a simple personal portfolio website I made using HTML, CSS, and JavaScript. It includes an About Me section, two projects, a contact form, and a greeting that changes depending on the time of day.

## Setup Instructions
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

No extra installation is needed.
