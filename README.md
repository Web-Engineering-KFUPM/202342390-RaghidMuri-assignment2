# Raghid Muri Portfolio - Assignment 2

## Project Description

This project is an improved version of my personal portfolio from Assignment 1. The main goal of Assignment 2 was to make the website more interactive and improve the user experience using JavaScript.

The website includes an About Me section, a Projects section, and a Contact section. Compared to Assignment 1, this version adds interactive project descriptions, contact form validation, user feedback messages, and smoother navigation link transitions.

## Features

- About Me section
- Two projects with images
- Show and hide project descriptions using JavaScript
- Contact form with input validation
- Error message when required fields are empty
- Error message when the email address is invalid
- Success message when the form is filled correctly
- Greeting message that changes based on the time of day
- Smooth hover transition on navigation links
- Responsive layout using Flexbox

## Setup Instructions

To run the project locally:

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No extra installation, packages, or backend are required.


## AI Usage

I used ChatGPT throughout this assignment as a support tool while improving my portfolio from Assignment 1. It helped me understand and implement the new interactive features, including showing and hiding project descriptions, validating the contact form, displaying user feedback messages, and adding a smooth hover transition.

I also used ChatGPT for debugging, explaining JavaScript and CSS behavior, reviewing code structure, and improving the project documentation. I did not use every suggestion exactly as given; I reviewed the output, tested it, and changed parts of it to better match my own design and understanding.

A more detailed explanation of how AI was used, including benefits, challenges, learning outcomes, and modifications, is available in:

`docs/ai-usage-report.md`

## How to Use

- Use the navigation links to move between the About, Projects, and Contact sections.
- Click `Show Description` under a project to display its description.
- Click `Hide Description` to hide the description again.
- Fill in the contact form and press `Send`.
- If a field is empty, an error message will appear.
- If the email address is invalid, the website will ask for a valid email address.
- If the form is filled correctly, a success message will appear.
